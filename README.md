# Titanic EDA & Data Visualization - CodeAlpha Internship

## Task 1 - Exploratory Data Analysis

**Dataset:** Titanic Dataset (Kaggle)

**Tools Used:** Python, Pandas, Seaborn, Matplotlib, Google Colab

### Analysis Performed:
- Checked shape, info, null values & statistics
- Survival Count Analysis
- Survival by Gender & PClass
- Age Distribution Analysis
- Correlation Heatmap

### Key Insights:
- Female passengers had a much higher survival rate
- 1st Class passengers survived more than others
- Younger passengers were in majority
